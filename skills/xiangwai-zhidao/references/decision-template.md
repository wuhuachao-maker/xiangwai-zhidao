# 决策交付模板（默认对用户不显式展示内部术语的大段解释）

## 简洁版（默认）
**结论**：我建议现在优先做 X，暂时不要做 Y。

**定果**：真正要获得的是……，而不是表面指标……。

**观局**：目前可证实的生态、相关方与约束是……。

**寻根／对岸**：最值得优先处理的是……关系；证据……；尚不确定的是……。

**定策**：今天执行 A（具体对象、动作、次序）；停止/延后 B；若出现 C 信号则调整为 D。

在用户要求短答时只写「结论 + 原因 + 行动 + 边界」四句即可。

## 复杂版（需事实检索与重大选择）
1. 结论（主决策，先给出）
2. 目标与实际限制
3. 局势证据（来源、时间、样本是否可比）
4. 核心对岸、互根关系与反证
5. 执行路径（今天／本周／之后），谁做什么、何时调整
6. 不做什么与风险底线
7. 未知项只列会改变结论的部分；必要时调取探岸法

## 探岸模式
无法识别关键原因时，优先让模型先自行检索和分析已有资料。只有证据明显不足时，建议能产出最高信息价值的最小对照，不要默认“问五个人/试三条视频”。

## 评价量表（非编造数值评分）
- 是否采用四步内核，而非名人观点堆砌？
- 是否辨认了外部生态和多方关系？
- 对岸是否为具体制约条件，而非抽象“补情绪”？
- 行动是否具体到执行主体和优先级？
- 哪条证据能支持，什么结果会改变当前判断？
- 是否坚守用户明确的服务、隐私和风险约束？
