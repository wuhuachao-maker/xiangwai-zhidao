# 候选互根规律｜使用条件与反例

> 本文件仅给出推理候选框架。不可将模型视为所有情形已经验证的定律。根据问题检索事实和可比案例。

| 模型 | 何时值得考虑 | 可能存在的对岸 | 不宜机械使用 |
|---|---|---|---|
| 供需错位 | 有产出无购买 | 客户正在付费解决的具体需求 | 需求存在不代表支付能力存在 |
| 目标替代 | 忙于播放量、粉丝等 | 实际利润、咨询或长期价值 | 曝光有时也是有效中间指标 |
| 单点瓶颈 | 多环节共同构成结果 | 最窄环节的必要条件 | 不可仅凭低指标判定因果 |
| 专业与可感知价值 | 技术强、客户不了解 | 客户可理解的结果与风险控制 | 高专业门槛场景仍需专业细节 |
| 信任与交易风险 | 高价成交困难 | 证据、评价、交付承诺、风险划分 | 并非所有交易都由信任主导 |
| 生态错位竞争 | 直接竞争成本高 | 未充分服务的细分场景 | 细分空间可能没有规模或利润 |
| 借势与依赖 | 早期资源不足 | 平台、合作伙伴、现有生态资源 | 防止单一平台或伙伴锁定 |
| 集中与冗余 | 资源紧缺或环境剧变 | 主攻重点与风险缓冲之间的关系 | 过度集中/过度分散均可能失效 |
| 能力圈与迁移 | 机会很多难以取舍 | 已掌握的优势与跨界学习成本 | 能力圈会改变，不是永远不变 |
| 边际收益 | 加倍投入未增结果 | 新约束或递减回报 | 数据口径变化时不能妄下结论 |
| 反馈与延迟 | 行动后没有立刻见效 | 系统响应周期与二次效应 | 不等于所有延迟都会转化成好结果 |
| 未知盲区 | 所有熟悉解释都无效 | 未观察的变量、关系、外部因素 | 不以随便测试替代明确决策 |
