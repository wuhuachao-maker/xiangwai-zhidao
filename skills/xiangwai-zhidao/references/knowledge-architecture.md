# 长期知识库规划｜来源辅助，内核主导

## 规模是规划，不是现有库存
- 长期方向：1000+研究人物、15000+思想卡、30000+真实案例卡、3000+跨案例对照卡；不可为了达成数量指标大量拆分、重复或制造内容。
- 一期：先建立可靠规范与少量高质量可比案例，再扩大采集。完成度以可追溯、去重、完整性和决策适配为准。

## 四种资料对象
1. **思想源头卡**：人物、原作、原文链接、时间、原意、引用限额与事实/观点类型。
2. **决策案例卡**：目标、当时局势、已知约束、选择、行动、结果、代价、失败/未实现情况。
3. **互根规律卡**：触发条件、关系、适用边界、支持案例、反对案例、可执行动作。
4. **决策反馈卡**：用户授权的旧决策、行动、时间、结果及新失衡。默认严格私有，不自动进入公共案例库。

## 人物研究方向（不等于权威排序）
- 东方哲学与思辨：老子、庄子、王阳明等。
- 矛盾与实践：毛泽东《矛盾论》《实践论》及不同历史解释。
- 战略竞争：孙武、克劳塞维茨等。
- 企业创新：马斯克、贝索斯、乔布斯等。
- 长期投资与取舍：巴菲特、查理·芒格、霍华德·马克斯等。
- 科学、生态与系统：达尔文、诺伯特·维纳等。
- 认知与行为：卡尼曼、赫伯特·西蒙等。
- 组织、风险、管理：德鲁克、德明、塔勒布等。
- 补齐普通人和普通企业的失败、幸存、转型与反例，防止只看名人造成幸存者偏差。

## 知识图谱关系
人物 → 原始思想 → 当时决策 → 适用环境 → 结果 → 支持/反证 → 象外规律 → 现实行动。检索优先从用户问题结构出发，再返回人物或案例。

## 采集与授权
- 不批量转载受版权保护的原书和课程；保存自撰摘要、准确少量引文及原始来源链接。
- 不公开用户、客户的私密咨询材料。共享案例必须有明确授权，并去标识化；敏感与专业保密内容默认不存。
- 实时检索只能由宿主提供联网/搜索工具；Skill 本身不具备自动大规模采集、更新或保证数据准确的能力。
