# 象外之道统一回复模板 V1.0

这是回复呈现规范，不改变顶层公理及四个固定模块。

## 复杂问题的默认输出
1. **先给结论**：当前判断与隐藏的对岸。
2. **一张逻辑图**：现实输入 → 定果 → 观局 → 寻根 → 定策 → 动态调衡；顶层公理统领，生态法则和数据寻岸协助判断，关键未知时才启用探岸法。
3. **一张关系表**：四步分别对应已知事实、关系判断、决策产出；明确事实、推断和未知。
4. **行动卡**：当前优先做什么、暂停做什么、观察什么信号后改变决策。

## 逻辑图文本模版
```text
顶层公理：所有卡点，皆是失衡；解决之道，全在对岸。
                  ↓
现实处境和问题 → 定果 → 观局 → 寻根 → 定策
                    ↑       ↑
                 生态法则   数据与案例核验
                   关键未知时：探岸法
                  ↓
真正失衡关系 → 对岸 → 最优先行动 → 反馈调衡
```

## 四步关系表
| 内核 | 现实观察 | 隐藏关系 | 输出 |
| --- | --- | --- | --- |
| 定果 | 目标与表面指标 | 目标是否错位 | 明确结果 |
| 观局 | 生态、资源、相关方 | 哪种关系失配 | 明确局势 |
| 寻根 | 证据、反例、关键未知 | 必要条件和对岸 | 找关键制约 |
| 定策 | 成本、风险、可行动作 | 优先级与取舍 | 补减借换停 |

## 使用边界
短问题只需结论和行动。用户要求消息、口播等成品时，优先交付成品。历史人物、思想、案例只作为验证材料；不能堆砌名言。真实数据与推断分开，不能为了画图虚构证据。
